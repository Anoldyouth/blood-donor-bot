# blood-donor-bot

Ловит слот на сдачу тромбоцитов в Центре крови им. О.К. Гаврилова: новая дата
(сегодня+3) открывается в 12:00 МСК, места разбирают за 10–90 секунд.

| Приоритет | Сайт | Отделение |
|---|------|-----------|
| 1 | https://donor-mos-sab.online | Шаболовка, 57 |
| 2 | https://donor-mos.online | Беговая, Поликарпова 14 |
| 3 | https://donor-mos-zar.online | Царицыно, Бакинская 31 |

## Как работает

Всё общение с сайтом идёт обычными HTTP-запросами (`httpx`):

1. За 3 минуты до 12:00 бот входит на каждый сайт (`POST /auth.php`) и каждые 15 с
   входит заново: сессия живёт 30–60 с.
2. Кабинет `/account/` запрашивается каждые 0,35 с, до 3 запросов одновременно.
   Ответ читается только до конца таблицы дат.
3. Появилась свободная дата → берётся самая ранняя дата и самое раннее время → одна
   заявка `POST /wp-json/gse/form-v2/send` с полями из формы сайта.
   **Приоритет** — порядок сайтов в `config.yaml`. Сайт, нашедший слот, сначала
   ждёт свежий ответ от сайтов выше (обычно меньше секунды, не дольше
   `priority_wait_sec`, 2 с). Если слот есть и у них, записывается самый верхний.
   Пропущенные сайты не ждут.
4. После первой принятой заявки остальные сайты останавливаются, а бот
   встаёт на паузу на 14 дней (`state.json`) и шлёт уведомление в Telegram.
   Если новая дата уже разобрана («места закончились»), бот прекращает ловить
   до завтра: места не возвращаются.

**Браузер нужен только для капчи.** Сервер проверяет `smart-token` у Яндекс
SmartCaptcha, а получить токен может только настоящий браузер. Бот держит
один headless Chromium с вкладкой на каждый сайт. На вкладке открыт только
виджет капчи по адресу сайта: страница подставляется локально, в кабинет
браузер не заходит. Клик по галочке даёт токен за 0,3–1 с. Токен держится
наготове и обновляется раз в минуту. Если Яндекс вместо галочки показывает
задание (на Шаболовке так было во всех попытках 24.10–28.10), токены для этого
сайта заранее заказываются в rucaptcha (`CAPTCHA_API_KEY` в `.env`). Решение там
занимает 30–70 с, но токен живёт 7–10 минут (замер 28.10), поэтому бот с начала
окна держит запас из двух токенов и обновляет их, пока они не устарели. Около
1 ₽ за токен, обычно 2–4 токена за день. Без ключа такой сайт в этот день
пропускается, а остальные его не ждут.

Одна заявка на все сайты: отклонённая заявка блокирует аккаунт на 5+ часов, а
записи на близкие даты в разных отделениях не подтверждаются. Запускайте
бота одним процессом: второй вход на тот же сайт выбивает первую сессию.

## Установка

Нужен Python 3.11+.

```bash
python -m venv .venv
.venv\Scripts\activate            # macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
playwright install chromium
copy .env.example .env            # DONOR_LOGIN, DONOR_PASSWORD, CAPTCHA_API_KEY, по желанию Telegram
```

## Команды

```bash
python -m donor_bot check                 # вход, даты в кабинете и капча на каждом сайте; без заявки
python -m donor_bot once --dry-run        # ловить 60 с сейчас, заявку не отправлять
python -m donor_bot once --window 120     # ловить 120 с сейчас по-настоящему
python -m donor_bot run                   # каждый день в 12:00; окно терминала не закрывать
python -m donor_bot clear-pause           # снять паузу после записи
```

Флаги: `--site tsaritsyno` (можно несколько) ограничивает сайты, `--headful`
показывает окно браузера с капчей, `-v` включает подробный лог. Лог пишется в
`bot.log`.

## Настройка

Все параметры с комментариями лежат в `config.yaml`: сайты, время открытия,
окно, частота опроса, желаемое время (`preferred_times`), `dry_run`, пауза
после записи.

## Тесты

```bash
pip install pytest
python -m pytest tests -q
```

Тесты проверяют разбор кабинета, поля заявки (в том же порядке, что шлёт
сайт), расписание и логику отправки: повтор после 401, отказ, таймаут и то,
что на два сайта уходит ровно одна заявка.
