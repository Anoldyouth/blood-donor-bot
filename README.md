# blood-donor-bot

Записывает на сдачу тромбоцитов в Центр крови им. О.К. Гаврилова. Новая дата
(через 3 дня) открывается каждый день в 12:00 МСК, и места разбирают за минуту.
Бот в 11:57 входит на сайты Шаболовки, Беговой и Царицыно, в 12:00 ловит
свободное время, отправляет одну заявку и выключается. Если записаться
не получилось, бот выключается в 12:05.

## Установка (один раз)

Нужен Python 3.11+.

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
playwright install chromium
copy .env.example .env
```

Откройте `.env` и впишите логин и пароль от сайта донора. Для Шаболовки нужен
ещё ключ rucaptcha.com (`CAPTCHA_API_KEY`, около 1 ₽ за запись), без него бот
Шаболовку пропускает.

## Запуск

```bash
.venv\Scripts\activate
python -m donor_bot check   # проверить вход на всех сайтах, ничего не отправляет
python -m donor_bot run     # ждать 12:00, записаться и выйти
```

Запускайте `run` до 11:57 и не закрывайте окно. Если запустить после 12:05,
бот будет ждать завтрашних 12:00. Запустите только одну копию бота: вторая
выбьет первую с сайта.

Результат виден в окне и в `bot.log`. Заявка, которую отправил бот, ждёт
подтверждения врача в личном кабинете. Если в кабинете уже есть заявка, бот
ничего не отправляет.

## Настройка

`config.yaml`: порядок сайтов (верхний важнее), желаемое время
(`preferred_times`), `dry_run: true`, чтобы ничего не отправлять.
